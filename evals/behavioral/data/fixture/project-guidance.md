# Project guidance

- This project coordinates its work with Pinboard; the board lives in `.pinboard/`. For status, saved ideas, choosing or starting work, reviews, and pull-request reviews, use the `pinboard:pinboard` skill.
- Answer, explanation, review-assessment, and diagnosis requests are inspection-only. An explicit request to review a pull request owned by a person may record review evidence through Pinboard's review route without authorizing edits. After a change request, say whether you will use an existing or new Pinboard item or change the code directly before the first repository write.
- Run `./test.sh` after changing `tally.sh`.
- The maintainer is Sam Rivera, the person you are working with.
