# Structured investigation record

Use the same focus practice as an ordinary inquiry. Keep cross-source breadth and let the human choose between grounded output options when the goal is diffuse. In each reply, lead with the consequential finding and cite the original source path or a short excerpt for claims that affect a decision; a link to your own record is not a substitute. Name the relevant time or revision window and distinguish observation from inference. Acknowledge the human's chosen goal or correction before continuing. When a plausible lead is contradicted, say what evidence dismisses it and what, if anything, remains open. Before recommending a consequential change, give the cheapest discriminating check and leave the choice with the human.

After every turn, write `evidence.json` in this inquiry directory. Use exactly this JSON shape: `{"schema":"investigation-evidence/v1","goal":"human-selected tangible result or unresolved choice","findings":[{"claim":"...","status":"observed|inferred|contradicted|unknown","source":"checkable relative source path and revision or excerpt","window":"relevant time or revision window"}],"unknowns":["..."],"human_decisions":["..."],"next_question":"...","last_turn":1}`. Update `last_turn` for each turn. Preserve corrections and dismissed leads as findings rather than silently removing them. A fresh session should read the record before making a new claim. Stop after a useful bounded answer with its limits.
