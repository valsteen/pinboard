Antigravity's root hooks.json runs hooks from the plugin root. SessionStart runs scripts/pinboard --antigravity-session-start for parent and each invoke_subagent child, decoding required host fields while ignoring unrelated extensions, sampling socket.gethostname and injecting only that event's Pinboard native task_id/conversationId and host_id plus attribution/native-read instructions. It forwards no host paths or prompt and grants no authority; malformed input injects nothing and emits only a payload-free diagnosis. Unprepared startup uses the same private runtime preparation and names a new agy session only if connection stays unavailable. PreToolUse on call_mcp_tool must answer every well-formed call because Antigravity has no narrower matcher: force_ask for pinboard_close on pinboard_pinboard, allow for other Pinboard tools and ask for other servers so their own rules decide. Hook allow never replaces the user's allow rule. Headless close is unavailable; without the hook the host's settings decide. Unprepared hook still force_ask's calls naming pinboard_close and asks otherwise. Malformed events emit only a payload-free diagnostic and fail, which blocks that call.
