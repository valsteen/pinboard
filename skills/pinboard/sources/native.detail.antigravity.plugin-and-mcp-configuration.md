Antigravity loads the repository root as a native plugin through `.antigravity-plugin/plugin.json`, the root `mcp_config.json` and the root `hooks.json`; it does not convert the Claude manifest. `mcp_config.json` declares command `sh` with arguments `${PLUGIN_ROOT}/scripts/pinboard --mcp`, because Antigravity expands `${PLUGIN_ROOT}` only in arguments, environment and working directory, not in the command. It starts the shared `pinboard-mcp` entry through the same runtime owner as the other runtimes. Antigravity names the Pinboard server `pinboard_pinboard` and runs every MCP call, for every server, through its own `call_mcp_tool` tool with `ServerName`, `ToolName` and `Arguments`.
