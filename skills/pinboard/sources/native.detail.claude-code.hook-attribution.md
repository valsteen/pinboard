The parent entry validates the current SessionStart record and samples the machine name with `socket.gethostname()`. It adds only `Pinboard native parent task_id: "<actual session_id>"; host_id: "<actual machine name>"`, a concise attribution instruction and a pointer to this reference through native additional context. The host's SessionStart delivery refreshes those values on startup, resume and other native session refreshes; an emitted hook result alone does not prove native ingestion or agent adherence. The worker entry independently adds only `Pinboard native worker task_id: "<actual agent_id>"` to that worker's startup context and supplies no host value; its verified dispatch host remains separate.
