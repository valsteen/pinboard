The `pinboard_close` registration carries `_meta` `anthropic/requiresUserInteraction: true`, for which Claude Code v2.1.199 or later documents a per-call confirmation prompt that neither an allow rule nor the Pinboard PreToolUse allow skips, and a denial in `dontAsk` mode and non-interactive runs. Report a denied close to the human and seek no other route. Older Claude Code versions do not prompt.
