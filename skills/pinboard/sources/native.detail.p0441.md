Each entry decodes its exact Claude-owned event, validates required fields and ignores unrelated additive host fields. Ignored extensions, cwd and transcript paths are never forwarded. Pinboard-owned outputs, requests and artifacts remain strict regardless of sender. Missing or malformed required fields, a wrong event kind or invalid identity emit no attribution and only a payload-free diagnostic; machine-source failure cannot supply a guessed host. None of the three entries reads project state, creates a task, acquires a lease, authenticates credentials or changes saved permission policy; only the PreToolUse entry emits an approval decision.
