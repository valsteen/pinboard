Check that `invoke_subagent` is available, then call the returned `native_launch.tool` with exactly `native_launch.arguments`: `TypeName: "self"`, a one-line `Role`, and the complete shared launch message as `Prompt`. The `self` type starts a separate conversation with the parent's workspace, model and tools and none of the parent's transcript. The arguments deliberately omit `Model` and `Workspace`; another workspace would be a different source root. The envelope's `background` echoes the dispatch environment, while `invoke_subagent` takes no background flag and always runs the child asynchronously. Apply the same rule to candidate-read-only reviewers. A worker or reviewer subagent must send its final completion or blocker report to the parent conversation with `send_message` before stopping; plain response text is not relayed to the parent. If a launch used different arguments but changed neither source nor lifecycle, stop it and retry once from the unchanged recipe. If `invoke_subagent` is absent, stop native execution.
