Map already authorized access into the dispatch record and Claude permission controls. For an autonomous repository-writing worker, use Claude's normal edit-accepting mode; `dontAsk` can deny file writes instead of prompting. In an observed worker run in the Pinboard source repository, in auto permission mode, source edits in a linked checkout under `.claude/worktrees/` inside the owning session's launch directory needed no additional directory grant and caused no permission prompt or refusal; that is an observed result, not a runtime guarantee. A selected linked checkout or a shared work root outside the launch directory must be in Claude's allowed directories before dispatch; otherwise the owning task stops before dispatch and names that exact directory instead of launching a worker that cannot write it. Pinboard records declarations but neither grants nor enforces them.
