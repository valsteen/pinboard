# Generated SQLite code

Do not read, search, or edit Python in this directory during ordinary work. The canonical replacement-family behavior is declared in `codegen/replacements/declaration.py` and compiled by `codegen/replacements/compiler.py`.

Inspect generated Python only to diagnose a compiler or generated-output failure. Make the correction in the declaration or compiler, regenerate with `uv run --locked python -m codegen.replacements.compiler`, and keep Ruff and Pyrefly checking the result.
