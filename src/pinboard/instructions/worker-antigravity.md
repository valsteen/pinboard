## Close one representative contract

Before expanding a cross-boundary behavior across sibling variants, choose the cheapest supported value that can disprove agreement between the production owners and its real consumer.

1. Name the representative value, the observable consumer effect, and the production path between them.
2. Exercise that path through the application-owned boundary instead of proving each layer from separately constructed fixtures. When the path persists state, write it through the production operation and reload it from a fresh store before observing the consumer.
